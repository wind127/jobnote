# 求职记 · JobNote

把散在邮箱里的招聘进展，整理成一张看得懂的求职表：**哪个公司、哪个岗位、走到哪一步、接下来要做什么。**

![使用虚构数据展示的岗位进展表和待办表](docs/images/demo-dashboard.png)

*截图仅使用虚构演示数据。*

## 能做什么

- **看进展：** 按公司和岗位汇总投递、测评、笔试、AI 面试、一面、二面、三面和 Offer；状态会显示“待笔试”“待一面”等。
- **管待办：** 把测评、笔试、面试和回复事项放进待办表，显示截止时间与紧急程度；每 4 小时可向微信发送一份摘要。
- **核对来源：** 每条进展保留邮件证据。同岗位、同阶段的重复通知汇总为一行，改期采用最新安排；可以查看全部邮件证据并一次核对或忽略。公司、岗位或面试轮次不明确时保留待核对。

`腾讯企业邮箱 → 千问办公定时整理 → 本机网页 + 微信摘要`

目前是**本机单用户预发布版**：支持一个腾讯企业邮箱收件箱，复用本机 [`qqexmail` 技能](docs/QQEXMAIL_REFERENCE.md)。千问办公负责定时整理，并通过已连接的微信 IM 频道发送结果。Gmail、普通 QQ 邮箱和教育邮箱尚未接入。

## 先看演示

需要 Node.js 22.13+。演示无需邮箱账号，数据均为虚构。

```powershell
git clone https://github.com/wind127/jobnote.git
cd jobnote
npm ci
npm run demo
```

打开 <http://127.0.0.1:3211>。

## 复制给千问办公：自动部署

适用于 **Windows + 千问办公桌面端**。先准备 Node.js 22.13+、已安装的 `qqexmail` 技能、腾讯企业邮箱客户端授权码，并在千问办公中连接自己的微信 IM 频道。把下面整段发给千问办公；已有 `.env` 会保留，缺少的邮箱凭据需由你在本机补齐。

```text
请在这台 Windows 电脑上部署求职记 JobNote，并配置每 4 小时自动整理邮箱、把摘要发到我自己的微信私聊。项目地址：https://github.com/wind127/jobnote 。请直接执行，不要只给我步骤。

1. 如果当前工作区已有 JobNote 仓库，就使用它并保留本地改动；否则将项目克隆到当前工作区的 jobnote 目录。记住实际绝对路径，后续命令和定时任务都使用该路径。不要覆盖现有 .env 或 data/。
2. 检查 Node.js 是否至少为 22.13、qqexmail 技能是否已安装，以及千问办公微信 IM 频道是否已连接。进入项目目录运行 npm ci、npm run build。若 .env 不存在，从 .env.example 创建；只使用我已配置的邮箱账号、客户端授权码和技能路径。运行 node --env-file=.env dist/cli.js doctor，确认三项邮箱配置均为 true。缺少凭据时请指出缺哪项并等待我在本机配置，不要猜测或输出密钥。
3. 启动或复用本机 JobNote 网页服务，确认 http://127.0.0.1:3210/ 可以打开岗位进展与待办表。若端口被其他程序占用，不要结束那个程序；报告冲突。
4. 完整阅读 docs/QWENWORK_TASK.md。创建或更新唯一一项名为“求职记｜邮箱进展”的千问办公本地定时任务：以本机时区每隔 4 小时运行，工作目录为项目绝对路径。任务提示词应要求每次先读取该文档，再严格执行其中的邮件批次整理、字段规则和 finish 摘要流程；将文档中的示例路径替换为实际路径。把任务结果的接收位置明确设为我已连接的微信私聊会话，不要只留在桌面对话里，也不要使用 Server酱。若已有同名任务，请更新它，不要新建第二项。
5. 用该定时任务的“立即运行”执行一次完整联调，检查任务记录、网页数据和微信 IM 会话。若读信失败、邮件需要人工决定是否跳过、或微信接收位置不明确，请停止依赖该问题的步骤并告诉我具体原因；不要自行跳过邮件、重置数据库或宣称送达成功。只有在这次运行正常后才保持周期任务启用。
6. 最后简要报告项目路径、网页地址、任务名称与下次运行时间、首次整理结果，以及微信消息是否实际可核实。不要在回复或日志中展示授权码、完整邮件正文，也不要把 .env 或 data/ 提交到 GitHub。
```

千问办公支持[在对话中创建定时任务](https://docs.qwenwork.cn/desktop/scheduled-tasks)，并可将结果[发送到指定 IM 会话](https://docs.qwenwork.cn/desktop/im-channels)。电脑需要保持唤醒，任务才能按时执行。

## 手动接入自己的邮箱

先安装并配置 `qqexmail` 技能，再在项目目录执行：

```powershell
npm run build
Copy-Item .env.example .env
```

在 `.env` 中填写技能目录、腾讯企业邮箱账号和客户端授权码。然后运行：

```powershell
node --env-file=.env dist/cli.js doctor
node --env-file=.env dist/cli.js serve
```

打开 <http://127.0.0.1:3210>。接着按照[千问办公定时任务说明](docs/QWENWORK_TASK.md)，建立一项每 4 小时运行的任务，并将任务结果指定发送到已连接的微信 IM 会话。邮件读取为只读模式，网页和记录保存在本机；摘要由千问办公转发到微信。
